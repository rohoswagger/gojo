# Execution Lanes

## Correct

Verify the live claim against app code, pricing source, privacy implementation, release metadata, and public artifact. Correct every occurrence in the smallest PR. Add a contract that fails on stale facts.

Gate: authoritative source cited, rendered output checked, no contradictory occurrence remains.

## Repair

Fix one verified technical, indexing, speed, canonical, redirect, sitemap, schema, broken-link, or orphan defect. Prefer the root cause over a page-local patch.

Gate: regression test fails before and passes after; built/live route proves the expected behavior.

## Refresh

Improve an existing page when GSC shows low CTR, decay, wrong-query visibility, weak intent coverage, or missing internal links. Preserve working rankings and URL unless evidence supports consolidation.

Gate: title/H1/body/links align to one intent owner, claims are sourced, baseline saved for later comparison.

## Consolidate or prune

Merge overlapping intent into the strongest URL and use one-hop permanent redirects. Prune only when the page has no distinct reader value and no stronger repair/refresh case.

Gate: inbound internal links updated, redirect/canonical/sitemap behavior tested, traffic/query history recorded.

## Editorial

Validate query, intent, SERP shape, Gojo relevance, unique first-hand evidence, and conversion path before writing. Write one useful piece, not a keyword variant. Avoid formulaic AI prose and unsupported superlatives.

Gate: differentiated brief, factual draft, internal links both directions, metadata/schema/build checks, reviewed screenshots when UI changes.

## Programmatic

Execute one roadmap phase with a shared template, distinct source data, intent ownership, minimum-value rules, and indexation controls. Never scale before manually reviewing representative output.

Gate: sample pages are materially distinct and useful, no doorway pattern, generated inventory and sitemap validated.

## Tool

Build only when the tool completes a real search job and naturally connects to Gojo. The utility must work without signup unless the user benefit requires persistence.

Gate: functional tests, result accuracy, indexable explanatory copy, privacy review, and conversion path.

## AEO

Measure answer ownership with stable prompts and record citations/mentions. Improve concise factual answers, entity clarity, structured data, sourceability, and off-page corroboration. Do not manufacture citations or claim model behavior from one prompt.

Gate: prompt set/version/date recorded, claims sourced, rendered content and structured data verified.

## Distribute and off-page

Use relevant reputable directories, editorial contacts, communities, or existing relationships. Personalize one factual message. Track public routes, dates, and follow-up eligibility. Never buy links or guess contact addresses.

Gate: exact target and message recorded; public listing/readback or truthful blocked/prepared status recorded.

## Measurement

Instrument only a decision-blocking event with narrow semantics and privacy-safe payloads. Define what the event proves and what it does not prove.

Gate: source contract, failure handling, privacy assertions, production delivery evidence after merge/deploy.
