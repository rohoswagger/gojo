Private on-device dictation

Speak into the text field you are already using.

Updated 2026-08-10macOS 14+

What it does

Gojo’s dictation feature transcribes speech on your Mac and types the result into the active text field.

Why it is useful

It is useful when writing, replying, or capturing a thought is faster by voice, but you do not want to copy text from a separate transcription app.

How Private on-device dictation works in Gojo

  • Runs on-device without an API key or cloud transcription service
  • Uses explicit local model choices
  • Designed to type into the text field already in focus

Good to know

Dictation requires microphone permission and works best when the intended text field is active.

One workspace, not another standalone utility
